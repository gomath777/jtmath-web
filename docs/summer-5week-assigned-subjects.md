# 5주 여름특강 배정 과목 운영 메모

## 학생 안내 링크

학생에게 보내는 링크는 `https://jtmath.kr/5wsummer` 하나입니다.

학생은 안내받은 6자리 비밀번호만 입력합니다. 한 과목만 배정된 학생은 바로 해당 과목 캘린더로 이동하고, 두 과목 이상 배정된 학생은 본인에게 배정된 과목 카드만 봅니다.

## 서버 설정

실제 수강 명단은 코드에 넣지 않습니다. 서버 환경 변수 `SUMMER_5WEEK_ACCESS_ROSTER`에만 설정합니다.

지원 형식:

```text
100101:gs1,ds
110202:mj1
```

또는 JSON 배열:

```json
[
  { "pin": "100101", "subjects": ["mj1"] }
]
```

중복 PIN은 v1에서 과목 목록을 합칩니다. 엄격한 분리가 필요하면 별도 확인값을 추가하는 후속 작업이 필요합니다.

관리자 확인용 PIN은 `SUMMER_5WEEK_MASTER_PIN`으로 별도 설정합니다. 이 값은 모든 과목 카드를 열어 QA할 때만 사용합니다.

## 공개 규칙

정상 학생은 공개 시간이 지난 학습일의 링크만 볼 수 있습니다.

- 일요일 00:00 이후: 다음 월요일/화요일 자료 공개
- 수요일 21:00 이후: 다음 목요일/금요일 자료 공개
- 수요일/토요일 보충, 오답 총정리, 모의시험은 라벨만 표시

로컬 QA에서 시간 고정이 필요하면 `SUMMER_5WEEK_NOW`를 ISO 시간으로 설정합니다.
